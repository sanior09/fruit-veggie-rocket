## 🎯 กติกาและวิธีเล่น

ผู้เล่นจะรับบทเป็นนักบินอวกาศควบคุมจรวดที่ด้านล่างหน้าจอ เพื่อยิงกระสุนดาวใส่ **ผักและผลไม้** ที่ตกลงมาจากท้องฟ้าภายในเวลา **60 วินาที**

| เป้าหมาย | ประเภท | คะแนน |
| :--- | :--- | :---: |
| 🍎 แอปเปิล • 🍌 กล้วย • 🥕 แครอท • 🍉 แตงโม • 🍊 ส้ม | ผักและผลไม้มีประโยชน์ | **`+10`** |
| 🧁 เค้ก • 🍔 แฮมเบอร์เกอร์ | ขนม/ฟาสต์ฟู้ด (ระวังอย่ายิงโดน!) | **`-10`** |

### 🕹️ การควบคุมแสนง่าย
- **คอมพิวเตอร์:** เลื่อนเมาส์เพื่อบังคับจรวด แล้วคลิก (หรือกด `Spacebar` / ปุ่มลูกศร) เพื่อยิง
- **มือถือ / แท็บเล็ต:** แตะหรือลากนิ้วบนหน้าจอเพื่อบังคับจรวดและยิงกระสุน
- **โหมดช่วยเล่น (Auto-Fire):** กดปุ่ม `ยิงอัตโนมัติ` ที่แถบด้านบนสำหรับผู้เล่นทุกวัย

---

## ✨ ฟีเจอร์เด่นในเกม

- 🎨 **ภาพการ์ตูนเวกเตอร์วาดด้วยโค้ด 100%:** ใช้ `Canvas 2D API` วาดตัวละครน่ารักที่มีหน้าตา ขยับเอียงตามการบังคับ และแตกกระจายด้วยระบบ Particle
- 🔊 **ระบบเสียงสังเคราะห์ในตัว:** สร้างเสียงเอฟเฟกต์ยิง เสียงเก็บคะแนน และเสียงเตือนแบบการ์ตูนผ่าน `Web Audio API` (เปิด/ปิดได้)
- ⏱️ **HUD เรียลไทม์ & จบเกมใน 60 วินาที:** แสดงคะแนน เวลาถอยหลัง สถิติสูงสุด (`localStorage`) พร้อมสรุปดาวและปุ่ม **เล่นใหม่**
- 📱 **Responsive Design:** ปรับขนาดหน้าจออัตโนมัติ รองรับทั้งหน้าจอคอมพิวเตอร์ แล็ปท็อป แท็บเล็ต และสมาร์ตโฟน

---

## 🛠️ เทคโนโลยีที่ใช้ (สิ่งที่น้องๆ จะได้เรียนรู้ในสาขา IT)

1. **HTML5 & CSS3:** การออกแบบหน้าเว็บแบบ Responsive ปุ่มนูนสไตล์การ์ตูน 3 มิติ และการจัดวาง UI
2. **JavaScript (ES6+) & Game Loop:** การคำนวณฟิสิกส์การเคลื่อนที่ การตรวจจับการชน (Collision Detection) และการใช้ `requestAnimationFrame`
3. **HTML5 Canvas 2D:** การวาดกราฟิกและแอนิเมชันด้วยโค้ดคณิตศาสตร์และเรขาคณิต
4. **Web Audio API:** การสังเคราะห์คลื่นเสียงดิจิทัลบนเว็บเบราว์เซอร์
5. **Git, GitHub & Cloud Deployment:** การจัดการซอร์สโค้ดและการนำเว็บไซต์ขึ้นออนไลน์ผ่าน **Vercel**

## 📂 โครงสร้างไฟล์โปรเจกต์

```text
fruit-veggie-rocket/
├── index.html       # โครงสร้างหน้าเว็บ, แถบคะแนน HUD และหน้าจอเริ่ม/จบเกม
├── styles.css       # ตกแต่ง UI สีสันสดใสและรองรับทุกขนาดหน้าจอ
└── src/
    ├── sprites.js   # วาดตัวละครการ์ตูน จรวด กระสุน และฉากหลังด้วย Canvas 2D
    ├── audio.js     # ระบบสังเคราะห์เสียงเอฟเฟกต์ผ่าน Web Audio API
    └── game.js      # ลูปเกม ระบบนับคะแนน ตัวจับเวลา 60 วินาที และการควบคุม
```
